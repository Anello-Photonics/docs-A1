ANELLO Ground INS Gen 2 Integration Manual
==========================================

The ANELLO Ground INS Gen 2 combines one Silicon Photonics Optical Gyroscope (SiPhOG™) on the heading axis with navigation algorithms optimized for ground vehicles. This manual covers installation, configuration, external aiding, communication interfaces, and data collection.
