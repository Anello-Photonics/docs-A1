==================================
Sensor Calibrations
==================================

Speed Sensor Calibration
---------------------------------

Contact ANELLO at support@anellophotonics.com for recommended speed sensor calibration procedures.

(Optional) External Magnetometer Calibration
----------------------------------------------

If you will be supplying the ANELLO Ground INS Gen 2 with data from an external magnetometer via the ANELLO Proprietary Auxiliary RPH messages in :ref:`NMEA0183 <paprph-roll-pitch-heading-with-accuracies-anello-proprietary>` or :ref:`NMEA2000 <pgn-130817-auxiliary-attitude-anello-proprietary>`, you may conduct an optional external magnetometer calibration procedure to improve the accuracy of the reported heading.

Calibration procedures seek to cover all potential headings and motor power levels during operation. If you will be using an electric motor, limit changes in motor power during the data collection period to minimize abrupt changes in the magnetic field induced by the motor.

Contact ANELLO at support@anellophotonics.com for recommended external magnetometer calibration procedures.
